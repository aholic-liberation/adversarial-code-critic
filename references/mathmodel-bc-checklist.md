# 数学建模大赛 B/C 题批判清单

critic 每轮对照本清单逐条排查。每条都给出「典型症状」，帮你落到论文具体段落/公式/图表。本清单覆盖全国大学生数学建模竞赛（CUMCM）风格的 **B 类（优化/运筹/调度）** 与 **C 类（数据/统计/预测/评价）** 成果核查；其它赛制（美赛、华为杯）结构要求不同，只取通用条目（§3/§4）。

**来源**：CUMCM 论文范式（[MathModel-Skill 仓库的 cumcm-paper-standard.md](https://github.com/yushui2022/MathModel-Skill/blob/master/packages/claude/.claude/skills/paper-formal-writer/references/cumcm-paper-standard.md)，联网检索所得）+ 公开评阅惯例与破题共识（[数维杯 A/B/C 破题思路](http://www.0539edu.com/news/4172586/)、知乎历年题目分析）。

## 0. 先判题型（决定用哪一组）

- [ ] B 类判据：离散决策（选谁/排哪/建哪/走哪条路）、约束优化、调度/路径/分配/网络——重点查 §1。
- [ ] C 类判据：给数据集，要求分析/预测/评价/分类/关联——重点查 §2。
- [ ] 两套都必过 §3（通用结构）和 §4（交叉一致性）。

## 1. B 类（优化/运筹/调度）专项

- [ ] 决策变量定义完整吗？量纲、取值范围、下标含义写清了吗？（症状：公式里出现从未定义的符号）
- [ ] 目标函数与题设口径一致吗？有没有漏次要目标或擅自改目标？（症状：结果「最优」但成本口径与题意不符）
- [ ] 约束逐条核对：题设每条约束都进模型了吗？有没有自行添加约束而不说明？（症状：时间窗/容量/先后序约束丢失）
- [ ] 模型类型选择有理由吗（LP/MILP/NLP/DP/排队/图论）？与问题结构匹配吗？
- [ ] 求解算法与规模匹配吗？精确求解器是否说明时间限制与最优性 gap；启发式是否交代邻域结构、参数、迭代/收敛说明？
- [ ] 有没有最优性或下界论证？小算例有没有枚举/手算交叉验证？
- [ ] 结果可行性回验：报告的解逐条代回约束验证了吗？甘特图/路径图与数值表一致吗？
- [ ] 单位统一吗？（症状：时间窗按分钟、周期按小时混算）
- [ ] 对 NP-hard 问题宣称「多项式时间精确解」？——红旗，要求给证明或撤回表述。
- [ ] 只跑一个算例就下普适结论？算例规模与题设数据规模一致吗？

## 2. C 类（数据/统计/预测/评价）专项

- [ ] 数据预处理有依据吗：缺失值（删/插补）方式与理由、异常值判定标准、处理是否扭曲结论？
- [ ] 数据泄漏检查：划分在前还是预处理在前？时间序列是否混入未来信息？（症状：测试集参与归一化/特征筛选）
- [ ] 划分与验证交代了吗：留出/交叉验证？**只报训练集指标 = 红旗**。
- [ ] 特征/变量筛选有依据吗？共线性（VIF）检查了吗？构造特征有统计/业务理由吗？
- [ ] 统计严谨性：正态性/分布检验做了吗？假设检验有显著性水平与 p 值吗？多重比较校正了吗？
- [ ] 评价体系权重有依据吗（AHP/熵权/变异系数），还是拍脑袋？（症状：「权重取 0.3/0.3/0.4」无任何来源）
- [ ] 指标与题设口径一致吗？正负向指标、量纲、方向处理了吗？
- [ ] 相关系数被当成因果？（症状：「A 与 B 相关系数 0.9，因此 A 导致 B」）
- [ ] 样本量 vs 模型复杂度：小样本上复杂模型（深度网络/高维回归）有没有过拟合防护与说明？
- [ ] 时间序列：平稳性检验、差分、周期性处理了吗？预测区间给了吗？
- [ ] 可视化与数值一致吗：坐标/单位/样本量标注了吗？预测对比图与表内数值对得上吗？

## 3. 通用论文结构（B/C 都查）

- [ ] 摘要 800–1200 字、按子问题展开（模型+算法+关键结果+检验）？摘要数字与正文一致吗（**最常见硬伤**）？
- [ ] 问题重述有没有复制题面原文？必须压缩提炼、按子问题编号说明任务。
- [ ] 每问是否齐全：建模思路→变量定义→公式推导→目标/约束→求解算法步骤→结果表图→图表解释→结论回扣→检验/灵敏度？
- [ ] 模型假设：每条可检验吗？数量合理吗？与后文模型矛盾吗（假设独立后面却用相关模型）？
- [ ] 符号说明与正文一致吗？（症状：同一量在摘要、符号表、正文三种写法）
- [ ] 每张图/表都被正文引用，且有引导句与解释段？图题表题说清用途了吗？
- [ ] 公式前定义变量、后解释每一项含义？编号引用正确吗？
- [ ] 参考文献 5–8 条且正文实际引用，编号与文末一一对应？
- [ ] 模型评价四项（优点/不足/改进/推广）齐全吗？
- [ ] 代码附录存在吗？文中声称的结果能按附录代码复现吗（参数与正文一致）？

## 4. 交叉一致性（名实相符）

- [ ] 摘要宣称的精度/结论与正文结果部分对得上吗？
- [ ] 前一问的输出是后一问的输入时，衔接说明了吗（还是各问孤立建模）？
- [ ] 结论回答的是题目问的问题吗？（答非所问）
- [ ] 图表标题、单位、数量级与实际数据一致吗（差一个数量级、少个 0）？
- [ ] 「灵敏度分析」是真动了参数，还是只换了说法？扰动范围与结论量化了吗？
