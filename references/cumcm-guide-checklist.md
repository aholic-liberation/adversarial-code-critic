# 数学建模国赛（CUMCM）国奖核查清单

critic 每轮对照本清单逐条排查。来源：《2026 国赛·三天零基础速成国奖》书籍 OCR 整理。本清单聚焦「国奖级」硬性标准与高频致命扣分点，与 `mathmodel-bc-checklist.md` 互补：后者管「B/C 题题型专项」，本清单管「国赛规范与国奖标准」——两套都要扫。

## 0. 先判层次与题型（定基调）
- [ ] 目标层次：省奖（结构完整+格式合规即可）还是国奖（摘要量化+创新显性+三类检验齐全）？按层次定严格度。
- [ ] 题型归类：机理(A)/优化决策(B)/数据挖掘(C)，对应到 §1 评审标准的侧重点。

## 1. 评审标准四准则（满分100）
- [ ] 假设合理性（20分）：假设贴合实际、不脱离问题、必要且充分、不过度理想化。
- [ ] 建模创造性（30分）：模型针对性强、有改进、不堆砌、有创新。
- [ ] 结果正确性（30分）：结果可信可复现、数值合理、检验充分。
- [ ] 表述清晰性（20分）：结构完整、逻辑通顺、图表规范、排版美观。
- [ ] 评委阅读顺序：摘要(5-10分钟初审，差直接淘汰)→模型→结果→格式。

## 2. 论文结构（12模块，占比20%，缺失即扣）
- [ ] 模块齐全：题目/摘要/关键词/问题重述/问题分析/模型假设/符号说明/模型建立与求解/模型检验/模型改进与推广/优缺点/参考文献+附录。
- [ ] 顺序不可调换、模块不可缺失（省奖论文常缺检验/推广/符号说明）。
- [ ] 正文 30 页左右（不含附录/代码），不写目录；附录不计页数。

## 3. 全局格式（硬性扣分项）
- [ ] A4、页边距上下左右 2.5cm、版式统一。
- [ ] 中文宋体、英文/数字 Times New Roman；题目16号加粗居中、一级标题14号、二三级12号、正文12号。
- [ ] 单倍行距、首行缩进2字符、公式居中编号右对齐、无大段空白。
- [ ] 表上图下、三线表无竖线、编号连续不跳号不重号、图表高清原创不截图、无「如上表/如下图」模糊指代。
- [ ] 全文匿名：标题/页眉页脚/图表/附录/代码注释无姓名、学校、学号、Logo。

## 4. 摘要（占总成绩40%，初审第一关）
- [ ] 800-1000字、单页内（占3/4或4/5最佳）。
- [ ] 三段式：虎头(背景+问题)/猪肚(方法+创新+分问题量化结果)/豹尾(结果+检验+价值)。
- [ ] 纯文字：无公式、图表、问句、感叹句、引用标注。
- [ ] 每个子问题都带「模型+算法+量化结果」。
- [ ] 含至少两种检验（灵敏度/稳健性/误差/多模型对比/仿真）。
- [ ] 数据与正文完全一致、零夸大、误差/提升率保留1-2位小数。
- [ ] 摘要最后写、至少改5遍、字数不足600字或超一页即扣。

## 5. 四大得分模块（评委必看）
- [ ] 模型假设：3-5条、真实/简化/平稳/参数/无干扰五类、每条带合理性解释、不与后文矛盾。
- [ ] 符号说明：三线表、符号/含义/单位三列、全文统一无冲突、无滥用字母。
- [ ] 灵敏度分析：关键参数±10%/20%扰动、观察结果变化幅度、幅度大→敏感。
- [ ] 误差分析：RMSE/MAPE/相对误差、说明误差来源与可控范围。

## 6. 三大必做检验（缺一即判「不完整不严谨」）
- [ ] 误差分析（预测/拟合/机理必写）：RMSE、MAPE、R²、残差分析。
- [ ] 灵敏度分析（优化/评价/多参数必做）：参数±10%扰动、结果偏差<5%为稳健。
- [ ] 稳健性检验（全题型通用）：换算法/换样本/调区间，结论一致、无偶然性。

## 7. 高频致命扣分点（逐条对照）
- [ ] 摘要无量化结果/逻辑混乱/空话泛滥。
- [ ] 缺误差/灵敏度/稳健性任一检验。
- [ ] 图表无编号标题单位、图文不符、截图模糊。
- [ ] 公式错乱、符号不统一、量纲缺失、编号混乱。
- [ ] 大段照搬原题/网络、重复率超标。
- [ ] 代码缺失、无注释、无法复现求解结果。
- [ ] 匿名不彻底、残留个人/学校信息。
- [ ] 模型堆砌、与赛题场景严重脱节。
- [ ] 正文无数据、无推导、无结果。

## 8. 查重与合规红线
- [ ] 重复率≤20%；模型原理/理论表述自主改写；图表/代码/仿真原创。
- [ ] 匿名违规（姓名/学校/学号/Logo/标识）→ 直接作废。
- [ ] 按时提交 MD5+论文+支撑材料，逾期无效；改文件必须重新生成 MD5。
- [ ] 源码完整可复现、注释清晰、数据可复现。

## 9. 模型选用（名实相符）
- [ ] 模型服务问题，不「为用模型而用模型」、不堆砌生僻模型。
- [ ] 适配优先、推导清晰、针对性强、可解释。
- [ ] 同一问题 2-3 种模型对比择优，写明选型理由。
- [ ] 结果能讲通、符合现实，不做「模型玄学」。

## 10. 终稿五步校验
- [ ] 内容校验：所有子问题已解、逻辑闭环、无遗漏错误。
- [ ] 格式校验：字体行距缩进标题层级统一。
- [ ] 细节校验：公式图表编号连续、量纲标注完整。
- [ ] 匿名校验：全文排查隐私信息。
- [ ] 导出校验：PDF 排版分页清晰度正常、无乱码错位缺页。
